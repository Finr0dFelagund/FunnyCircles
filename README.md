# FunnyCircles

Интерактивный симулятор поведения взаимодействующих частиц (клеточный автомат с непрерывной физикой) на C++ и Qt Widgets.

Приложение моделирует множество круглых частиц, которые притягиваются, отталкиваются, сталкиваются и образуют устойчивые связи. Все физические законы и типы частиц настраиваются прямо в интерфейсе, а сцену можно сохранить в файл и загрузить обратно.

## Возможности

- Непрерывная физика взаимодействующих частиц: притяжение и отталкивание по закону, близкому к гравитационному.
- Настраиваемые типы частиц: цвет, имя, размер, масса, коэффициент трения, жёсткость, направления взаимодействия и лимит связей с каждым другим типом.
- Упругие связи между частицами с настраиваемой жёсткостью и порогом разрушения.
- Многопоточный расчёт с независимой частотой обновления физики и отрисовки.
- Инструменты редактирования: добавление, удаление, перетаскивание, выделение области, заморозка частиц.
- Сохранение и загрузка сцены в формате CSV.
- Глобальные настройки симуляции с сохранением в `settings.ini`.

## Требования

- C++17.
- Qt 5 или Qt 6 с модулем Widgets.
- CMake не ниже 3.5.
- Компилятор с поддержкой C++17: MSVC, MinGW или GCC/Clang.

## Сборка

```bash
cmake -S . -B build
cmake --build build --config Release
```

Готовый исполняемый файл `CellAutomatV2` появится в каталоге `build` (для многоконфигурационных генераторов — в `build/Release`).

Если Qt установлен в нестандартный каталог, укажите путь к его CMake-конфигурации:

```bash
cmake -S . -B build -DCMAKE_PREFIX_PATH=/path/to/Qt/6.x.x/gcc_64
```

## Использование

При запуске создаётся демонстрационная сцена: по 500 частиц каждого из пяти предустановленных типов в случайных точках. Симуляция при этом остановлена, отрисовка включена.

### Левая панель инструментов

| Кнопка | Действие |
|--------|----------|
| `add` | Добавить частицу. Открывает палитру типов; после выбора типа клик по сцене создаёт частицу. Доступно только при остановленной симуляции. |
| `del` | Удаление. Клик по частице или выделение рамкой удаляет частицы. |
| `mov` | Переключение подвижности: делает выбранные частицы неподвижными или подвижными. |
| `col` | Переключение участия частиц в столкновениях. |
| `con` | Создать связь: два клика по разным частицам. |
| `unCon` | Удалить связь: два клика по разным частицам. |
| `stp` | Остановить частицы: клик или выделение рамкой обнуляет скорость. |
| `rmAlB` | Удалить все связи выбранной частицы или всех частиц в области выделения. |
| `grb` | Захват: перетаскивание частицы мышью. |
| `new type` | Редактор типов частиц. |

Для выделения области зажмите левую кнопку мыши на пустом месте сцены и протяните рамку. Действие, применённое к рамке, совпадает с активным инструментом (`del`, `mov`, `col`, `stp`, `rmAlB`).

### Нижняя панель инструментов

| Кнопка | Действие |
|--------|----------|
| `sim` | Запуск и остановка симуляции. |
| `rend` | Включение и отключение отрисовки. |
| `load` | Загрузка сцены из CSV-файла. |
| `clr` | Очистка сцены. |
| `save` | Сохранение сцены в CSV-файл. |

Слайдер справа внизу задаёт скорость симуляции: длительность шага изменяется экспоненциально, от быстрого режима до почти остановленного.

### Кнопка настроек `set`

Открывает панель физических параметров, сохраняемых в `settings.ini`:

- включение связей, полей (гравитации), трения и столкновений;
- максимальная скорость частиц (`-1` отключает ограничение);
- длина связей и жёсткость связей;
- ускорение свободного падения;
- длительность шага симуляции и время обновления картинки в миллисекундах;
- количество частиц на один поток исполнения.

Медленный режим удлиняет шаг симуляции и применяется при изменении параметра `updateTime`.

### Добавление частицы с начальной скоростью

При активном инструменте `add` зажмите `Shift` и левую кнопку мыши в точке создания: протяните курсор в направлении и на расстояние, задающее начальную скорость, затем отпустите кнопку. Вектор скорости отображается линией.

### Редактор типов

Форма позволяет задать имя, цвет (`QColorDialog`), размер, массу, трение и жёсткость нового типа, а также заполнить матрицу взаимодействий: направление (притяжение или отталкивание) и максимальное число связей с каждым существующим типом. Существующие типы можно удалить из того же окна. Типы сохраняются в `settings.ini` в секции `[Types]` и восстанавливаются при следующем запуске.

## Форматы файлов

### Сцена (CSV)

Первая строка — количество частиц. Далее для каждой частицы записываются две строки:

```
<количество частиц>
<x> <y> <vx> <vy> <имя типа>
<collisionAble> <moveAble>
```

Связи и пользовательские типы в файл не записываются. При загрузке тип частицы сопоставляется по имени среди типов, описанных в `settings.ini`; для неизвестного имени поведение не определено.

### settings.ini

Файл `settings.ini` создаётся в рабочем каталоге приложения. Секция `[General]` хранит параметры симуляции, секция `[Types]` — массив описаний типов частиц.

## Структура проекта

| Файл | Назначение |

| `main.cpp` | Точка входа, генерация демонстрационной сцены. |

| `celltype.*` | Описание типа частицы и реестр типов. |
| `globalvars.*` | Глобальные физические параметры и функция силы. |
| `settingswidget.*` | Панель физических параметров. |
| `addcellwidget.*` | Палитра выбора типа при добавлении частицы. |
| `typecreationwidget.*` | Редактор типов частиц. |
| `CMakeLists.txt` | Сборочные инструкции. |

## Известные ограничения

- Сохранение сцены не включает связи и пользовательские типы; загрузка зависит от содержимого `settings.ini`.
- Демонстрационная сцена создаёт 2500 частиц, что заметно нагружает слабые машины.
- Ограничение скорости отрисовки не влияет на расчёт: при включённой симуляции физика продолжает обновляться.
